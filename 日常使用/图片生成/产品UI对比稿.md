## 产品 UI 对比稿

它能轻松生成同一个功能的多种设计方案，方便你横向对比、做决策。

### 提示词模板

为 #功能/页面：您想要对比的设计# 创建 3 套 UI 设计稿，展示不同的设计思路：

1. **第一套**：走极简风，信息密度高，强调效率
2. **第二套**：视觉更丰富，功能更突出
3. **第三套**：大胆创新，重新想象这个交互可以怎么做

**统一要求**：

- 使用 #品牌色：您想要使用的品牌色# 作为配色
- 填充真实感的占位数据

> 三套设计要各有特色，但都要能落地实现。
